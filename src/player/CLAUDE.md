# Player Portal Prototype
Consumer-facing. Mobile-first at 480px. Light mode default. Four surfaces: Dashboard,
Practice, Rounds, My Journey. The timeline IS the data model — My Journey is the full
chronological record, other tabs are filtered lenses. "Ask Looper" chat overlay (floating
button, bottom-right). Session recaps in plain language. Practice accountability.
Freemium: free / Pro $9.99/mo / Coach tier included with academy.
