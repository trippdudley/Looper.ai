# Coach Portal Prototype
Full web app — the between-lesson command center. Desktop-first, 1200-1400px max width.
Light mode default. Features: dashboard (upcoming lessons, player status, weekly digest),
player roster with longitudinal progress, session history (searchable, filterable),
practice plan builder, program design tools. Post-session detailed view lives here (full
lesson record expanded by phase, editable). This is where the coach does deliberate work.
